## Featured Projects

**Quantum Surface Code Visualizer**
Quantum error correction visualizer simulating stabilizer measurement cycles on neutral atom hardware (QuEra). 1st Place, MIT iQuHACK 2026.

**FinQuest**
Financial decision support platform using RAG architecture with pgvector for semantic retrieval and LangChain for multi-step agent orchestration. HawkHack 2025 Award Recipient.

**Farm Buddy**
Offline-capable, multilingual voice assistant for rural farmers using Llama 3, Whisper, and Piper TTS, with a full-stack system designed for low-connectivity environments. YHack 2026.

**Aurora**
Retail and B2B diamond platform with PostgreSQL schemas for listings, bids, pricing, and certification, plus role-based access control and analytical dashboards.

**Screenz.ai Interview Platform**
Production LLM pipelines using the Anthropic API with chain-of-thought prompting, response validation, and hallucination mitigation, powering AI-driven candidate evaluation at scale.

**UniFind**
Verified campus marketplace and lost and found platform for MSU.
